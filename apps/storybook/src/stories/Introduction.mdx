# Omnitok UI Kit

Biblioteca de componentes React para sistemas administrativos y productos internos. Esta es la **línea v3** (`@omnitok/ui` 3.x), el look de la plataforma BI de Omnitok; su criterio de diseño está en `DESIGN.md`, en la raíz del repo.

## 🎨 Características

- **React 18 + TypeScript** - React moderno con type safety completo
- **Tailwind CSS** - Styling con tokens de diseño personalizados
- **Accesible** - Construido con accesibilidad en mente
- **Customizable** - Fácil de personalizar con CSS variables y Tailwind
- **Monorepo** - Organizado con pnpm workspaces
- **Storybook 10** - Documentación interactiva de componentes

## 📦 Instalación

### Pre-requisitos

```bash
npm install lucide-react
```

Si tu proyecto usa Tailwind CSS, consulta la sección [🎯 Tailwind Preset](#-tailwind-preset) para configurar los tokens de diseño del UI Kit.

### Paquete principal

```bash
# Línea v3 (canal pkg-v3, una etiqueta v3.x.y por versión)
npm install github:pervasivemind/omnitok-ui-kit#pkg-v3

# package.json
"@omnitok/ui": "github:pervasivemind/omnitok-ui-kit#pkg-v3"
```

La rama `pkg` sigue en 0.2.x para los productos que no migraron. Las notas de cada versión, con las de migración, están en `packages/core/CHANGELOG.md`.

## 🚀 Uso Básico

El shell v3: cabecera de marca navy, sidebar enmarcado y el bloque de cuenta al pie.

```tsx
import { Button, Card, Layout, SidebarAccount } from '@omnitok/ui';
import '@omnitok/ui/styles.css';
import { BarChart3, FolderOpen, Settings } from 'lucide-react';

function App() {
  const sidebarItems = [
    { id: '/', label: 'Inicio', icon: <FolderOpen size={16} /> },
    {
      id: '__section_reports__',
      kind: 'section',
      label: 'Reportes',
      children: [{ id: '/reports/availability', label: 'Disponibilidad', icon: <BarChart3 size={16} /> }],
    },
    { id: '/settings', label: 'Configuración', icon: <Settings size={16} /> },
  ];

  return (
    <Layout
      brandHeader={{ brandText: 'Mi Sistema', label: 'Inicio' }}
      sidebarItems={sidebarItems}
      activeSidebarId="/"
      onSidebarItemClick={(item) => {
        if (!item.id.startsWith('__')) navigate(item.id); // las secciones no son rutas
      }}
      sidebarFooter={
        <SidebarAccount
          name="Ana Pérez"
          detail="ana@cliente.com"
          version="1.4.0"
          languages={[{ code: 'es' }, { code: 'en' }, { code: 'pt' }]}
          language="es"
          onLanguageChange={setLanguage}
          onSignOut={signOut}
        />
      }
      sidebarFooterCollapsed={<SidebarAccount collapsed name="Ana Pérez" />}
    >
      <Card>
        <Button variant="primary">Comenzar</Button>
      </Card>
    </Layout>
  );
}
```

Sin `brandHeader`, `Layout` conserva la forma v0.2 (logo en el sidebar y cabecera blanca) para los productos que todavía no migran.

## 🎯 Tailwind Preset

El UI Kit exporta un **preset de Tailwind CSS** con todos los tokens de diseño (colores, tipografía, spacing, sombras, animaciones, etc.).
Esto permite que tu proyecto use las mismas clases utilitarias que los componentes internos del kit, manteniendo consistencia visual.

### Instalar Tailwind CSS

Si tu proyecto aún no tiene Tailwind CSS, instálalo junto con sus dependencias:

```bash
npm install -D tailwindcss @tailwindcss/postcss postcss autoprefixer
```

Crea un archivo `postcss.config.js` (o `.mjs`) en la raíz de tu proyecto:

```js
export default {
  plugins: {
    '@tailwindcss/postcss': {},
    autoprefixer: {},
  },
};
```

### Configurar el preset

Importa el preset de `@omnitok/ui` en tu `tailwind.config.ts` (o `.js`) y agrégalo al array `presets`:

```ts
import type { Config } from 'tailwindcss';
import omnitokPreset from '@omnitok/ui/tailwind-preset';

const config: Config = {
  presets: [omnitokPreset],
  content: ['./src/**/*.{js,ts,jsx,tsx}'],
};

export default config;
```

### ¿Qué incluye el preset?

| Token | Ejemplo de clase | Descripción |
|---|---|---|
| **Colores** | `bg-primary`, `text-accent`, `border-success` | Colores de marca, semánticos, chart |
| **Tipografía** | `font-sans` (Inter), `font-display` (Nunito Sans), `font-mono` (Open Sans) | Familias y tamaños; `text-2xs` es el piso de 11 px |
| **Spacing** | `w-sidebar`, `w-sidebar-collapsed` | Espaciados personalizados |
| **Sombras** | `shadow-card`, `shadow-modal` | Box shadows |
| **Gradientes** | `bg-[image:var(--omni-gradient-action)]` | El degradé de la acción primaria (variable que el cliente puede cambiar) |
| **Animaciones** | `animate-fade-in`, `animate-slide-in` | Transiciones |

### Importar estilos de componentes

El preset solo agrega los tokens de diseño. Para usar los componentes estilizados del kit, también necesitas importar el CSS compilado:

```tsx
// En tu entry point (main.tsx o App.tsx)
import '@omnitok/ui/styles.css';
```

> **Tip**: Puedes usar el preset sin los componentes si solo necesitas los tokens, o combinar ambos para el flujo completo.

## 📝 Convenciones

1. **El look vive en el componente**: no se restylea un componente del kit desde afuera.
2. **Una acción primaria por zona**; el resto secundaria, outline o ghost.
3. **Cabeceras blancas** en tarjetas, tablas y modales; el navy es solo del marco.
4. **Nunca solo color**: cada estado lleva palabra o ícono.
5. **Íconos de Lucide** exclusivamente.
6. **Responsive**: encabezados, acciones y pestañas envuelven en vez de desbordar.

## 🤖 MCP Server (AI IDE Integration)

Omnitok UI Kit cuenta con un servidor **MCP (Model Context Protocol)** que permite a editores con IA consultar la documentación y especificaciones de los componentes directamente desde el IDE. El MCP v3 sirve dos catálogos juntos: el del kit y el de los componentes BI de la plataforma (bi-components y dashboard-render, que este Storybook muestra en la sección BI).

**Endpoint**: `https://ui-kit-v3.omnitok.cloud/mcp`

### Configurar en Cursor

Agrega la siguiente entrada en `.cursor/mcp.json` (a nivel de proyecto o global):

```json
{
  "mcpServers": {
    "omnitok-ui-kit": {
      "url": "https://ui-kit-v3.omnitok.cloud/mcp"
    }
  }
}
```

### Configurar en VS Code (Copilot)

Agrega la entrada en `.vscode/mcp.json`:

```json
{
  "servers": {
    "omnitok-ui-kit": {
      "type": "sse",
      "url": "https://ui-kit-v3.omnitok.cloud/mcp"
    }
  }
}
```

### Configurar en Windsurf

Agrega la entrada en `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "omnitok-ui-kit": {
      "serverUrl": "https://ui-kit-v3.omnitok.cloud/mcp"
    }
  }
}
```

### ¿Qué puedes hacer con el MCP?

Una vez conectado, tu asistente de IA puede:

- **Listar todos los componentes** disponibles en el UI Kit
- **Consultar la documentación** de un componente (props, variantes, ejemplos)
- **Generar código** usando los componentes correctos con sus props reales
- **Entender el Design System** (colores, tipografía, patrones)

> **Tip**: Después de configurar el MCP, prueba pedirle a tu asistente: *"Usa los componentes de Omnitok UI Kit para crear un formulario de registro"*.
