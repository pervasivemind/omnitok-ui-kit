# Omnitok UI v3

El kit de la plataforma BI de Omnitok (`@omnitok/ui` 3.x). Este Storybook muestra solo la línea v3: lo que define `DESIGN.md` (raíz del repo, aprobado el 2026-10-25) y lo que dibujan el portal, el builder y la consola. Los componentes BI (gráficos, KPIs, tablas, composición del reporte) están en la sección **BI** de la barra lateral.

**North Star: "The Calm Control Room".** Un solo marco navy (cabecera y sidebar) que se queda quieto; el canvas frío y las superficies blancas llevan el trabajo. El color se usa poco y con significado: rosa para la única acción primaria de cada zona, violeta para lo compartido y lo seleccionado, verde para la pestaña del módulo. Los estados siempre llevan palabra o ícono.

## Instalación

```bash
# Línea v3 (canal pkg-v3, una etiqueta v3.x.y por versión)
npm install github:pervasivemind/omnitok-ui-kit#pkg-v3 lucide-react
```

```tsx
// En el entry point (main.tsx)
import '@omnitok/ui/styles.css';
```

Las notas de cada versión, con las de migración, están en `packages/core/CHANGELOG.md`.

## El shell v3

Cabecera de marca navy, sidebar enmarcado con su selector de proyecto y el bloque de cuenta al pie. Detalle y variantes en **Layout / Shell v3**.

```tsx
import { Button, Card, Layout, SidebarAccount } from '@omnitok/ui';
import { BarChart3, FolderOpen, Settings } from 'lucide-react';

function App() {
  const sidebarItems = [
    { id: '/', label: 'Inicio', icon: <FolderOpen size={16} /> },
    {
      id: '__section_reports__',
      kind: 'section',
      label: 'Reportes',
      children: [{ id: '/reports/availability', label: 'Disponibilidad', icon: <BarChart3 size={16} /> }],
    },
    { id: '/settings', label: 'Configuración', icon: <Settings size={16} /> },
  ];

  return (
    <Layout
      brandHeader={{ brandText: 'Mi Sistema', label: 'Inicio' }}
      sidebarItems={sidebarItems}
      activeSidebarId="/"
      onSidebarItemClick={(item) => {
        if (!item.id.startsWith('__')) navigate(item.id); // las secciones no son rutas
      }}
      sidebarFooter={
        <SidebarAccount
          name="Ana Pérez"
          detail="ana@cliente.com"
          version="1.4.0"
          languages={[{ code: 'es' }, { code: 'en' }, { code: 'pt' }]}
          language="es"
          onLanguageChange={setLanguage}
          onSignOut={signOut}
        />
      }
      sidebarFooterCollapsed={<SidebarAccount collapsed name="Ana Pérez" />}
    >
      <Card>
        <Button variant="primary">Comenzar</Button>
      </Card>
    </Layout>
  );
}
```

## Tailwind preset

El preset trae los tokens de v3 (colores, tipografía, sombras, radios, animaciones), así una pantalla usa las mismas clases que los componentes.

```ts
import type { Config } from 'tailwindcss';
import omnitokPreset from '@omnitok/ui/tailwind-preset';

const config: Config = {
  presets: [omnitokPreset],
  content: ['./src/**/*.{js,ts,jsx,tsx}'],
};

export default config;
```

| Token | Ejemplo de clase | Para qué |
|---|---|---|
| Colores | `bg-primary-soft`, `text-neutral-800`, `border-success` | Marca, estados y la escala de grises |
| Tipografía | `font-sans` (Inter), `font-display` (Nunito Sans) | `text-2xs` es el piso de 11 px |
| Sombras | `shadow-card`, `shadow-modal` | La elevación de tarjetas, menús y modales |
| Degradé de acción | `bg-[image:var(--omni-gradient-action)]` | Solo el botón primario |

## Componentes

- **Acciones:** Button (primario, secundario, outline, ghost; danger, accept e info solo en diálogos de confirmación).
- **Campos:** Input, Textarea, Select, MultiSelect, Checkbox y Toggle, Radio, CodeEditor, FileDropzone.
- **Contenido:** Card, Badge, Avatar, Alert, Table, Tabs, Pagination, Breadcrumb, Dropdown.
- **Capas:** Modal y ConfirmModal, SidePanel, Toast.
- **Layout:** Shell v3 (Layout con `brandHeader`), BrandHeader, SidebarAccount.
- **Páginas:** LoginPage en pantalla dividida.

## Convenciones

1. **El look vive en el componente**: no se restylea un componente del kit desde afuera.
2. **Una acción primaria por zona**; el resto secundaria, outline o ghost.
3. **Cabeceras blancas** en tarjetas, tablas y modales; el navy es solo del marco.
4. **Nunca solo color**: cada estado lleva palabra o ícono.
5. **Íconos de Lucide** exclusivamente.
6. **Responsive**: encabezados, acciones y pestañas envuelven en vez de desbordar.

## MCP

El servidor MCP v3 sirve los dos catálogos de este Storybook (el kit y los componentes BI) a los editores con IA.

**Endpoint**: `https://ui-kit-v3.omnitok.cloud/mcp`

```json
{
  "mcpServers": {
    "omnitok-ui-kit": {
      "url": "https://ui-kit-v3.omnitok.cloud/mcp"
    }
  }
}
```

Con el MCP conectado, el asistente puede listar los componentes, leer sus props y variantes y generar código con los componentes reales.
